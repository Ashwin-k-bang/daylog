# Daylog
Upload ALL files to the repo root: index.html, daylog.html, category.html, sync.js, sw.js, icon-*.png
Do NOT upload a data/ folder (the app creates data/daylog.json itself; uploading one would overwrite your logs).
Open https://<user>.github.io/<repo>/ . Each device needs the GitHub token once: tap "Set up sync",
or open  https://<user>.github.io/<repo>/#token=YOUR_TOKEN  once on that device.
