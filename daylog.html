Sync across devices

Your data is saved in your GitHub repo (data/daylog.json), so every device that opens this site shows the same logs. Each device needs the token once.

  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories, pick this repo
  3. Permissions → Repository → Contents: Read and write
  4. Generate, copy, paste above
